# Multi-Account Browser Workflow & Gemini 4 Argon Dispatch Guide

This guide details how to leverage 8–12 Gemini Pro / Advanced accounts across browser sessions (Demon Browser, Chrome profiles, Edge, or automation agents) to execute complex coding workloads using **Gemini 4 Argon**.

---

## 1. Gemini Web UI ("Task" Mode + 4 Argon)

In the official Gemini web interface (`https://gemini.google.com`):

### UI Landmarks (from User Environment):
- **Input Bar**: Look for the pill selector directly below or beside the main prompt box.
- **Mode Toggle**: Switch from **Chat** to **Task**.
  - *Why Task mode?* Task mode allocates an expanded execution context, enabling continuous reasoning and code synthesis.
- **Model Selector**:
  - Click the model dropdown (which may default to `3.8 Flash`).
  - Select **`4 Argon`** (`Complex tasks`).
- **File Upload**:
  - Click the **`+`** (plus) attachment icon on the left side of the prompt input.
  - Upload `argon_context.zip` (generated by `Package-ArgonContext.ps1`).
- **Prompt**:
  - Paste the engineered prompt from `templates/argon_task_prompt_template.md`.

## 2. Google AI Studio Workflow (`gemini-4-argon`)

For raw, unconstrained reasoning and code execution:

### Direct Link:
`https://aistudio.google.com/prompts/new_chat?model=gemini-4-argon`

### Recommended Settings (from Screenshot 2):
1. **Model**: `Gemini 4 Argon (gemini-4-argon)`
2. **Thinking Level**: Set to **`High`** (maximizes chain-of-thought analysis for complex refactoring).
3. **Tools**:
   - Enable **Code execution** (allows Argon to verify logic and test scripts internally before answering).
   - Grounding: Optional (enable if checking latest third-party library docs).
4. **Context**:
   - Drag and drop `argon_context.zip` or individual source files into the chat area.
   - Run Ctrl+Enter.

## 3. Managing 8–12 Pro Accounts & Quota Rotation

When handling heavy refactorings across large codebases, hitting daily limits on a single account is common.

### Profile Isolation:
1. **Demon Browser / Multi-Profile Setup**:
   - Maintain dedicated profiles: `Account_01` through `Account_12`.
   - Each profile stays permanently logged into one Google Pro account.
   - Keep cookies/session persistent so no 2FA re-prompt occurs.

### Rotation Strategy:
- **Round-Robin Task Distribution**:
  - Account 01: Initial deep architecture review or large refactoring.
  - Account 02: Bug fix iteration and patch verification.
  - Account 03: Test suite generation.
- **Quota Limit Signal**:
  - When Gemini Web shows "You've reached your limit for Gemini 4 Argon, switching to Flash...", switch browser profile or tab to the next active Pro account.

## 4. Automation & Agentic Dispatch (Demon Browser / Puppeteer / Playwright)

If using a browser automation script or Demon browser extension:
1. **Target URL**: `https://gemini.google.com/app` or `https://aistudio.google.com/prompts/new_chat?model=gemini-4-argon`
2. **Selectors (Gemini Web)**:
   - Task Mode: Button/pill containing text `"Task"`.
   - Model Selector: Click dropdown button containing `"Flash"` or model name, select element containing `"4 Argon"`.
   - File Input: `input[type="file"]` or trigger file dialog via `+` button.
3. **Automation Safety**:
   - Always verify that the file uploaded is clean of sensitive `.env` files (enforced by `Package-ArgonContext.ps1`).
